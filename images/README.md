# Images

Déposer ici uniquement des assets effectivement utilisés par le portfolio.

Convention recommandée :

```
project-slug-cover.webp
project-slug-desktop.webp
project-slug-mobile.webp
project-slug-detail-01.webp
```

Éviter les assets lourds non optimisés et les images dont la licence ou l'origine n'est pas claire.

Tant qu'un visuel n'existe pas, la case prévue reste un placeholder visible (`VISUEL À VENIR`) — ne pas la supprimer ni la remplacer par une capture inventée.
