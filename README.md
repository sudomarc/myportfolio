# Personal Portfolio

Portfolio personnel orienté **preuve de travail, crédibilité et contact**.

## Stack

- Next.js 16 App Router
- React 19.3
- TypeScript
- Tailwind CSS 4.3+
- ESLint
- Déploiement cible : Vercel

## Démarrage

```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:3000.
