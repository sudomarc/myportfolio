# Roadmap

## Phase 0 — Fondation
- [x] Virage vers un site 100 % statique (HTML/CSS/JS, sans framework).
- [x] Poser la gouvernance et l'architecture statique.
- [x] CI statique (contrôle structurel, sans npm).
- [x] Pages légales avec placeholders.
- [x] Positionnement public : Web Dev, sans publication de statut personnel ni de localisation.
- [x] Contact public limité à GitHub ; aucun numéro personnel ni e-mail direct publié.

## Phase 1 — Direction artistique
- [x] Direction Dark Editorial / Digital Studio documentée.
- [x] Tokens (couleurs, typographie, espacements, rayons, motion) dans `styles.css`.
- [ ] Finaliser le système typographique avec une vraie décision de marque.
- [ ] Créer ou sélectionner les assets réels (captures projets).

## Phase 2 — Homepage
- [x] Hero final (identité publique, positionnement, disponibilité, CTA sans localisation personnelle).
- [x] Sélection de projets avec statuts `REAL` / `DEMO` / `CONCEPT`.
- [x] Projet mis en avant (Amplio Web).
- [x] À propos.
- [x] Capacités.
- [x] Processus.
- [x] Contact.
- [x] Footer légal.

## Phase 3 — Case studies
- [x] Fiche par projet (structure complète : contexte → liens).
- [x] Compléter contexte, contraintes et décisions réels pour Amplio Web, Interact-Conakry et CrazyCook.
- [ ] Liens de démo vérifiés ; les dépôts GitHub des projets sont identifiés.
- [x] Résultats marqués non mesurés lorsqu’aucune mesure fiable n’est disponible.

## Phase 4 — Qualité
- [ ] Responsive vérifié en navigateur (360 / 390 / 768 / 1024 / 1440 px).
- [ ] Accessibilité clavier, focus, contraste vérifiés en navigateur.
- [ ] SEO : sitemap + canonical une fois le domaine vérifié.
- [ ] Open Graph : image réelle une fois les assets disponibles.
- [ ] Performance images (WebP, dimensions, lazy loading).
- [ ] Vérification navigateur complète (console, réseau, clavier).

## Phase 5 — Publication
- [ ] Connecter Vercel.
- [ ] Définir et vérifier l’URL de production ; aucune URL n’est inventée.
- [ ] Ajouter domaine personnalisé.
- [ ] Finaliser les informations légales et d’hébergement après vérification de la production.
- [ ] Publier v1.0.

## Hors scope initial

- CMS, base de données, authentification, dashboard.
- Blog complet.
- Formulaire de contact (avant choix du fournisseur).
- Analytics avant validation de la proposition de valeur.
